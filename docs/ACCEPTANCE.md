# v0.1 Alpha 验收记录

日期：2026-09-05。本记录区分已执行验证和尚未完成的验收，不把测试数量当作旧行为等价证明。

## 已执行

- 全工作区 TypeScript 检查和生产构建通过。
- Vitest：190 项通过，6 项真实模型测试/评测跳过。这次运行显式启用了实际导入样本测试。
- Playwright：7 项通过，实际 Edge 浏览器 + 本地 Fastify + 构建后的 WebUI + 假模型。
- 桌面 1440×1000、手机 390×844 截图人工检查；手机没有横向溢出。
- 三协议均使用真实 Pi 适配器和 Pi Agent 循环，离线 SSE 夹具覆盖：文本、工具、缓存使用量、推理签名/加密项回传、HTTP 错误、取消、重复工具限制。
- 双输出一次结算、失败重试、Swipe/Continue 不增加回合、分支 Memory/状态/世界事件隔离、提案原子应用与安全撤销、API 密钥脱敏和资产白名单均有集成测试。
- 可信 SDK 的上下文、工具作用域、整轮 hook、事件投影和拒绝远程 UI/任意工具有测试。

Playwright 流程：自动旁白 + 角色；用户旁白 + 指定 AI 旁白；Swipe/Continue；设置与 Memory/状态编辑；手机显式角色；旧分支恢复；群聊 Planner；连接创建（部分合并在同一测试）。

## 明确尚未完成 / 限制

1. **未调用真实 API。** 三个真实连接冒烟测试和三个 protected 权限模型评测默认关闭。模型支持的推理、工具格式、输出质量和缓存实际命中仍要逐连接验收。
2. **旧 121 项自定义行为尚未逐编号迁移/对齐。** 新测试包含参数化状态校验，不代表原 121 项已全部重写。旧 Memory 的独立手动/自动范围、字数触发和累计批次扩窗等细节仍需继续对照。
3. Lorebook 实现关键字、次关键字、常驻与排序；高级正则、递归、概率、装饰器、旧 depth/position 的完整放置语义未重现。未知字段保留，导入预览会警告。
4. protected 是强提示约束，不是可以保证语言模型绝不越权的形式化权限系统。真实评测也不能替代用户阅读检查；未执行评测前不能宣称模型层保障通过。
5. 当前 UI 的 Lore 条目/状态高级编辑仍使用 JSON；成文以安全纯文本显示，不执行角色卡 HTML/JS。移动端 PWA 是应用外壳，不是离线本地模型或离线聊天数据库。
6. 连接只有一套配置：Planner/Writer/记录维护复用聊天连接，未提供旧扩展各自的 Custom API 配置器。
7. 内部 SDK 已接入服务端生命周期；第三方加载、可视化插件设置编辑器、自动挂载的插件 UI 不在这一版开放。
8. Changed-source 导入采用保留新旧副本，不进行覆盖式同步或聊天增量合并。导入大小上限为每文件 32 MB / 每批 256 MB。
9. 未做 LAN 真机/HTTPS 和大规模长时间稳定性验收。本地 Key 为明文 SQLite，需自行保护本机账户；不适合直接暴露公网。

自动背景、图片生成、附件、TTS、MCP、Shell、任意网络工具、云端多用户、Docker-first 和第三方插件市场按计划排除。

## 后续方向（Minimalist）

以上是已有验收的历史记录，不是每次改动都要重跑的清单。后续遵循 AGENTS.md 的 Minimalist 原则：优先实际聊天体验与 Lore/Memory 编辑体验，只针对具体改动做必要检查；不再以旧 121 项逐项对齐为目标，不默认执行全量回归或源目录 SHA-256 比对。付费模型测试仍需显式配置测试环境，不从旧酒馆读取 Key。
