# 设计边界

仅保留维护时需要遵守的取舍；字段、接口、默认值和已实现流程直接查代码。

## 设置与故事

- 通用行为统一应用于所有新旧聊天，聊天只保存故事资料；不新增聊天级模型、生成模式或记录维护覆盖。界面少面板、少开关、少重复入口，复杂设置按需展示。
- 未知信息保持未知，不猜测发言者、死亡状态或旧记录的覆盖范围，不转换无法识别的旧格式；不批量补写旧记录。
- 固定事实和主角的故事前经历由用户维护，不能交给自动摘要或模型改写。候选行动、未应用草稿和模型推理不能当作已发生剧情写入故事记录。

## 模型上下文

- Memory 必须完整发送当前分支的有效阶段；用户固定的历史范围和重建批次也必须完整发送。预算不足应阻止请求并提示调整，不静默删减，不额外调用模型做检索或审核来替代完整发送。
- 性能与缓存优化不能改变模型上下文的语义、用户指定的范围或指令权限；不为缓存把 Memory 前移到历史正文之前，或把作者注释降级为 User。
- 预览以 Gateway 真实请求为依据；估算、上下文说明和历史验收记录不能代替实际请求或本次验收。供应商缓存命中和用量以实际返回为准，缺失不伪造。
- 认证 Header 始终不得输出；不把供应商推理状态混入普通写作的历史正文。

## 界面与编辑

- 语言与外观变化只影响显示，不改写故事、存储键或模型提示词，不触发内容保存或模型请求。
- 编辑时保持光标与滚动位置稳定；保存失败保留草稿，后续操作先等待必要的保存，不用过期结果覆盖用户的新修改。
- 修改旧消息或切换单条消息版本只替换该位置，保留当前后续消息和 Memory／主角状态，不自动重算记录。需要回到更早位置时使用明确的删除操作；独立分支仅由分支入口创建。
- 配色覆盖正文、旁白、辅助文字与交互状态；窄屏和缩放后仍能导航、发送并滚动弹窗。只引用本机字体并提供回退，不打包或下载系统字体文件。
