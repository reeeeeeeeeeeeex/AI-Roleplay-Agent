# v0.1.0 Alpha — AI Roleplay Agent

首个公开预览版：一个本地优先的 AI 角色扮演与故事创作工作区。

## 中文

- 角色卡、主角 Persona、群聊与旁白，独立的平行故事分支。
- 世界书、Memory、六张主角状态表，以及每个聊天独立的作者注释。
- 普通写作、Writer Agent、Planner＋Writer；支持 Chat Completions、Anthropic Messages 和 OpenAI Responses。
- 手动创作与网页提示词复制，中英文界面、阅读配色和字体设置。
- 请求预览、Trace、故事包与 Markdown 导出，以及支持的 SillyTavern 数据导入。

### 下载与启动

1. 安装 **Node.js 24（含 npm）**：https://nodejs.org/ 。无须另装 pnpm 或 Git。
2. 下载本页的 **AI-Roleplay-Agent-v0.1.0.zip** 或 **.tar.gz**，完整解压到可写目录。它们包含构建好的程序；GitHub 自动生成的 Source code 包需要首次构建。
3. Windows 双击 **Start.cmd**；macOS 双击 **Start.command**，或在终端运行 `sh ./Start.command`；Linux 在终端运行 `sh ./Start.sh`。
4. 首次启动会联网准备固定版本的依赖，之后打开 http://127.0.0.1:4310 。保持终端开启，按 Ctrl+C 停止。没有自动打开浏览器时可手动访问此地址。

数据默认保存在 `apps/server/data/`。更新前停止服务并备份整个目录；不要用新的空目录覆盖已有数据。模型 API、自动记录更新和主动生成操作使用你配置的服务商；项目不附带模型或 API 额度。

这是 Alpha 版本，数据格式仍在演进。启动检查覆盖 GitHub 托管的 Windows、macOS、Linux 环境，不代表已经验证每个发行版、架构或桌面环境。SQLite 依赖通常使用预编译组件；若设备没有对应组件，安装可能需要本机编译工具。

## English

The first public preview of a local-first workspace for AI roleplay and storytelling.

- Character cards, protagonist Personas, group chats, a narrator, and independent story branches.
- Lorebooks, Memory, six protagonist-state tables, and per-chat author's notes.
- Plain writing, Writer Agent, and Planner＋Writer with Chat Completions, Anthropic Messages, and OpenAI Responses.
- Manual writing, prompts for AI websites, Chinese/English UI, reading themes, and font preferences.
- Request previews, traces, story packages, Markdown exports, and supported SillyTavern imports.

### Download and start

1. Install **Node.js 24 with npm** from https://nodejs.org/ . No separate pnpm or Git installation is needed.
2. Download **AI-Roleplay-Agent-v0.1.0.zip** or **.tar.gz** from this release and fully extract it into a writable folder. These assets contain the built application; GitHub's automatic Source code archives need a first-launch build.
3. Windows: double-click **Start.cmd**. macOS: double-click **Start.command**, or run `sh ./Start.command`. Linux: run `sh ./Start.sh` in a terminal.
4. The first launch downloads pinned dependencies, then opens http://127.0.0.1:4310 . Keep the terminal open and press Ctrl+C to stop. If the browser does not open, visit that address manually.

Data defaults to `apps/server/data/`. Stop the server and back up the entire directory before updating; keep your existing data. API writing, automatic record updates, and explicit generation actions use your configured providers. No model or API credits are included.

This is an Alpha release; data formats are still evolving. Startup checks cover GitHub-hosted Windows, macOS, and Linux environments, not every distribution, architecture, or desktop. SQLite normally uses a prebuilt native component; a local compiler toolchain may be needed if none is available for your device.
